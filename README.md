# BD Sheba - Bangladesh Public Services Directory

A fast, production-ready Flutter app for quick access to Bangladesh government and public services.

## Features
- **Fast Directory**: Over 100+ services indexed.
- **Search & Filter**: Real-time debounced search.
- **Popular Services**: View counts tracked locally for popularity tagging.
- **Favorites**: Star your most-used services for quick access.
- **Recent History**: Keep track of the last 20 services you visited.
- **Material 3 Design**: Modern, premium look with dark/light mode support.
- **Bilingual**: Seamless toggle between Bangla and English.
- **Custom Font**: Uses `Kalpurush` for beautiful Bangla typography.
- **Offline Support**: Data is pre-loaded and cached.

## Tech Stack
- **Flutter**: Latest stable.
- **Riverpod**: State management.
- **Hive**: Local persistence.
- **url_launcher**: External browser integration.
- **flex_color_scheme**: Premium theme configuration.

## Setup Instructions
1. Clone the repository.
2. Ensure you have the `assets/fonts/kalpurush.ttf` file in the correct location.
3. Run `flutter pub get`.
4. Run `dart run build_runner build` to generate local storage adapters.
5. Launch the app with `flutter run`.

## Folder Structure
- `lib/models`: Data structures and Hive adapters.
- `lib/providers`: Riverpod state notifiers and persistence logic.
- `lib/screens`: All application screens.
- `lib/theme`: Premium theme data.
- `lib/widgets`: Reusable UI components like the Service Card.
- `lib/utils`: Localization and utility strings.
